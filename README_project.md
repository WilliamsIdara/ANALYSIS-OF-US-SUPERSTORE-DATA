ANALYSIS OF US SUPERSTORE DATA

This project analyzes sales data from a U.S. superstore to uncover trends and insights that aid in business decision-making.

Dataset:
The dataset used in this project was obtained from Kaggle, named SuperstoreUS (available [here](https://www.kaggle.com/datasets/amrboghdady74/superstoreus)).

The dataset was collated into a spreadsheet (Microsoft Excel) with columns including:

- `Order Priority`: High, Low, Critical, or Not specified.
- `Customer ID`: Unique ID for each customer.
- `Ship Mode`: Express Air, Delivery truck, Regular Air.
- `Customer Segment`: Corporate, Home Office, or Small business.
- `Product Category`: Office Supplies, Furniture, or Technology.
- `Order ID`: Unique ID for each order.
- `Ship Date`: Delivery date of the order.
- `Order Date`: Date when the order was made.
- `Region`: West, Central, or East.
- `Product Container`: Wrap box, Jumbo drum, Small pack, Medium box, or Jumbo box.
- `Postal Code`: Location.

Tools Used:
- Power BI for data visualization and analysis.
- Power Query for data cleaning.

How to Use:
To reproduce the analysis:
1. Download the CSV file from the repository.
2. Use Power BI to load the data for analysis and visualization.
3. Optionally, use Excel to explore the data before proceeding with Power BI.

Additional Notes:
- This analysis uncovers trends in sales and customer behaviors based on regions, shipping modes, and product categories.
